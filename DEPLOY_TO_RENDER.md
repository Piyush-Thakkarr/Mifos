# Deploy Client Portal to Render - Quick Guide

## ⚠️ IMPORTANT: What NOT to Deploy

- **DO NOT deploy Fineract** - It's already running on Render
- **DO NOT deploy PostgreSQL** - Already exists for Fineract
- **Only deploy these 2 services:**
  1. **Django Backend** (Client Portal API)
  2. **Angular Frontend** (Static Site)

---

## Prerequisites

- Render account access
- Git repository access
- Warp terminal (or any terminal)

---

## Step 1: Deploy Django Backend

### Option A: Using Render Dashboard (Recommended)

1. **Go to Render Dashboard**: https://dashboard.render.com
2. **Click "New +" → "Web Service"**
3. **Connect your repository** (select the repo)
4. **Configure the service:**
   - **Name**: `client-portal-backend`
   - **Environment**: `Python 3`
   - **Build Command**:
     ```bash
     cd portal_backend && pip install -r requirements.txt && python manage.py collectstatic --noinput
     ```
   - **Start Command**:
     ```bash
     cd portal_backend && gunicorn portal_backend.wsgi:application --bind 0.0.0.0:$PORT --workers 2 --timeout 120
     ```
   - **Plan**: Free (or Starter if needed)

5. **Add Environment Variables:**

   ```
   PYTHON_VERSION=3.11.0
   DJANGO_SECRET_KEY=<generate or use existing>
   DEBUG=false

   # Fineract Configuration (point to existing Fineract)
   MIFOS_BASE_URL=https://<your-fineract-service>.onrender.com/fineract-provider/api/v1
   MIFOS_TENANT_ID=default
   MIFOS_ADMIN_USER=mifos
   MIFOS_ADMIN_PASS=password
   MIFOS_VERIFY_SSL=false
   MIFOS_CLIENT_ID=3

   # Frontend URL (will be set after frontend deploys)
   FRONTEND_URL=https://<your-frontend-service>.onrender.com
   CORS_ALLOWED_ORIGINS=https://<your-frontend-service>.onrender.com
   ```

6. **Click "Create Web Service"**

---

### Option B: Using render.yaml (If using Blueprint)

**Skip this if using Option A above.**

The `render.yaml` file is already configured. Just:

1. Go to Render Dashboard
2. Click "New +" → "Blueprint"
3. Connect repository
4. Render will auto-detect `render.yaml` and create services

**⚠️ But REMOVE the Fineract and PostgreSQL services from render.yaml first!**

---

## Step 2: Deploy Angular Frontend

1. **Go to Render Dashboard**
2. **Click "New +" → "Static Site"**
3. **Connect your repository**
4. **Configure:**
   - **Name**: `client-portal-frontend`
   - **Build Command**:
     ```bash
     chmod +x build-frontend.sh && ./build-frontend.sh
     ```
   - **Publish Directory**: `dist/web-app/browser`
   - **Node Version**: `20.x`

5. **Add Environment Variables:**

   ```
   NODE_VERSION=20.x

   # Django Backend URL (from Step 1)
   DJANGO_API_URL=https://<your-backend-service>.onrender.com

   # Fineract API URL (existing Fineract)
   FINERACT_API_URL=https://<your-fineract-service>.onrender.com
   FINERACT_PLATFORM_TENANT_IDENTIFIER=default
   ```

6. **Click "Create Static Site"**

---

## Step 3: Update Backend Environment Variables

After frontend is deployed, update backend's `FRONTEND_URL` and `CORS_ALLOWED_ORIGINS`:

1. Go to backend service settings
2. Update environment variables:
   ```
   FRONTEND_URL=https://<your-frontend-service>.onrender.com
   CORS_ALLOWED_ORIGINS=https://<your-frontend-service>.onrender.com
   ```
3. Save and redeploy

---

## Step 4: Verify Deployment

1. **Check Backend Health:**
   - Visit: `https://<backend-url>/auth/login`
   - Should return JSON (not HTML error)

2. **Check Frontend:**
   - Visit: `https://<frontend-url>`
   - Should load the Mifos login page

3. **Test Client Portal:**
   - Click "Client Portal Login"
   - Login with: `client` / `password`
   - Should work!

## Troubleshooting

### Backend Issues:

- **503 Upstream Unavailable**: Check `MIFOS_BASE_URL` points to correct Fineract URL
- **CORS Errors**: Verify `FRONTEND_URL` and `CORS_ALLOWED_ORIGINS` match frontend URL
- **Build Fails**: Check Python version is 3.11.0

### Frontend Issues:

- **404 on routes**: Check `Publish Directory` is `dist/web-app/browser`
- **API calls fail**: Check `DJANGO_API_URL` environment variable
- **Build fails**: Check Node version is 20.x

