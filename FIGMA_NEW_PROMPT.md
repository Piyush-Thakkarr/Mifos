---

Design three new features for a **Mifos Client Portal** - a banking application interface for microfinance clients. Mifos is an open-source banking platform, and this client portal allows customers to manage their loans, savings, and financial activities.

## CONTEXT:

**What is Mifos Client Portal:**

- A web-based banking application for microfinance clients
- Allows clients to view loans, transactions, apply for new loans, and track applications
- Professional, clean, and functional interface
- Similar to online banking portals but for microfinance institutions
- Clients need to easily navigate and complete banking tasks

**Existing Design Style:**

- Clean, modern banking application interface
- Fixed left sidebar with navigation (white background)
- Main content area with light gray background
- White cards for content sections
- Professional blue color scheme (#1976d2 primary blue)
- Simple, readable typography
- Subtle shadows and rounded corners
- Functional and user-friendly, not flashy

## DESIGN THREE NEW FEATURES:

### FEATURE 1: Apply for New Loan

**What it is:**
A multi-step loan application form where clients can apply for new loans through the Mifos system.

**Requirements:**

- 3-step wizard: (1) Select loan product and basic details, (2) Enter loan terms and amount, (3) Review and submit
- Step 1: Product selection dropdown, dates (submitted on, expected disbursement), optional fields (loan officer, purpose, fund)
- Step 2: Principal amount, loan term, repayment frequency, interest settings, optional grace periods, collateral (if needed)
- Step 3: Summary of all entered information, repayment schedule preview, submit button
- Progress indicator showing current step
- Form validation and error states
- Clean, modern form design

**Design it as:**

- Functional multi-step form inside the Mifos client portal layout
- Use the sidebar + main content structure
- Each step in a clean white card
- Modern form fields with clear labels
- Visual progress indicator
- Make it feel professional and trustworthy

### FEATURE 2: Loan Application Status Tracker

**What it is:**
A page where clients can track the status of their loan applications through the approval process in Mifos.

**Requirements:**

- Show application details (ID, product, amount, dates)
- Visual timeline showing application progress:
  - Submitted → Pending Approval → Approved/Rejected → Disbursed
- Show dates and usernames for each stage
- Current status highlighted
- Timeline events table showing all actions
- Status badges (Submitted, Pending, Approved, Rejected, Disbursed)
- Color coding: green for completed, blue for current, gray for pending, red for rejected

**Design it as:**

- Status tracking page inside the Mifos client portal layout
- Application summary card at top
- Visual timeline component (vertical or horizontal)
- Clear status indicators
- Professional and informative
- Easy to understand at a glance

### FEATURE 3: Financial Calculators

**What it is:**
Financial calculation tools to help clients understand loan costs and compare products in the Mifos system.

**Requirements:**

- Loan EMI Calculator: Input loan amount, interest rate, tenure → Calculate monthly EMI, total interest, total amount
- Savings Maturity Calculator: Input principal, interest rate, tenure, compounding → Calculate maturity amount
- Interest Calculator: Simple interest calculations
- Product Comparison Tool: Compare two loan products side-by-side in a table
- Tabs or cards to switch between calculators
- Input fields on left, results displayed prominently on right
- Clean, modern calculator interface

**Design it as:**

- Calculator tools inside the Mifos client portal layout
- Each calculator in its own card or tab
- Modern input fields
- Results displayed clearly
- Comparison table matching existing table styles
- Make calculations feel instant and responsive

## DESIGN REQUIREMENTS FOR ALL THREE FEATURES:

**Layout Structure:**

- Fixed left sidebar (narrow, white background) with Mifos logo and navigation
- Main content area (light gray background) with sticky top header
- Top header: User info and notification bell
- Content flows in white cards below

**Visual Style:**

- Clean, modern banking application aesthetic
- Professional blue color scheme (primary: #1976d2)
- White cards on light gray background
- Subtle shadows and rounded corners
- Generous white space
- Clear typography hierarchy
- Simple, functional design

**Color Palette:**

- Primary Blue: #1976d2 (buttons, links, active states)
- White: #ffffff (cards, sidebar)
- Light Gray: #f5f5f5 (background)
- Medium Gray: #666 (secondary text)
- Dark Gray: #333 (primary text)
- Green: Success/active states
- Red: Errors/required indicators

**Components:**

- Cards: White background, rounded corners, subtle shadow, padding
- Buttons: Blue primary buttons, outlined secondary buttons
- Form inputs: Clean, modern, with labels
- Tables: Light gray headers, clean borders
- Status badges: Colored pills for different statuses
- Icons: Simple, consistent iconography

**What to Avoid:**

- NO marketing/landing page style
- NO large hero sections
- NO flashy animations
- NO dark backgrounds
- NO overly decorative elements
- Keep it professional and functional

**Design Principles:**

1. **Consistency**: All three features should look like they belong to the same Mifos application
2. **Usability**: Focus on making tasks easy to complete
3. **Clarity**: Information should be easy to scan and understand
4. **Modern**: Use contemporary design patterns while staying professional
5. **Trustworthy**: This is banking software - it should feel secure and reliable

**Make it:**

- Modern and polished
- Clean and uncluttered
- Professional and trustworthy
- Easy to use and navigate
- Consistent with banking application standards
- Visually appealing but not distracting

Design all three features with the Mifos client portal context in mind - this is a professional banking application for microfinance clients who need to manage their financial activities easily and securely.
